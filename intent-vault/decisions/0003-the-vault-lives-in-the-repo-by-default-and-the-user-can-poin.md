# The vault lives in the repo by default and the user can point it at another folder

## Context

Two layouts were in use: a vault inside the code repo and a separate Obsidian vault repo.

## Decision

The vault lives in the repo by default and the user can point it at another folder

## Why — the intent

Omar, 2026-10-27: "the user should choose but the default is in repo".

## Alternatives rejected

Always a separate vault repo; always in repo with no choice.
